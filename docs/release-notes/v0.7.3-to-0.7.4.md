# v0.7.3 → v0.7.4 升级参考（agent prompt）

把下面整段交给你的 coding agent 执行即可完成升级。全程不改业务代码，只刷新
llman-sdd 注入的项目脚手架与一处可选采纳项。

---

```markdown
本项目使用 llman-sdd（spec 驱动开发工作流 CLI）。CLI 已发布 0.7.4，项目 scaffold
可能仍是旧版。请按以下步骤升级，逐条执行并在结束时报告每步结果：

1. 版本核对
   - 运行 `llman-sdd --version` 与 `cat llmanspec/.context/sdd-state.json`。
   - 若前者 > 后者的 `cli_version`（或 state 文件缺失），需要执行第 2 步；一致则
     只需通读第 4 步确认行为变化，无需改动。

2. 刷新项目 scaffold（托管块与 skills）
   - 运行 `llman-sdd init --update`。
   - 它只刷新两类托管产物：根 `AGENTS.md` 与 `llmanspec/AGENTS.md` 的
     LLMANSPEC:START/END 托管块、`.agents/skills/llman-sdd-*`。手动写在托管块
     之外的内容（AGENTS.md 自有段落、项目规则）保留不动。
   - 刷新后 `git diff` 审阅：本次 0.7.4 的 skills 文案有整体文风修订（强度词
     四级化、行话清除），diff 较大属预期；确认无你的手写内容被覆盖即可提交，
     建议信息：`chore(sdd): init --update 至 0.7.4`。

3. 校验
   - `llman-sdd validate --all --strict` 必须全绿；若报
     `[NOTE] scaffolded with llman-sdd X; installed CLI is Y` 属版本提示，
     第 2 步完成后消失。
   - 项目若有自己的门禁（`just qa` 或等价），跑一遍确认无回归。

4. 0.7.4 行为变化知会（无需动作，除非你想采纳）
   - **模板文风治理**：内置 skills 模板全面改为中文强度词四级（必须/不得/宜/不宜/
     可/不必），清除行话与直角引号。若你的 agent 对 skill 文案敏感，重新读一遍
     `.agents/skills/llman-sdd-apply`（apply 循环与门禁证据措辞有实质收紧）。
   - **新增可选门禁 `check:stc`**：对 `packages/core/templates/**`（本仓特有）
     做中文文风 lint。一般项目无此目录则无感；模板类项目可参照
     `scripts/check-stc.ts` 自建。
   - **eval 剧本（若有 Harbor 评测）**：`eval/groups.yaml` 支持公网 https 端点
     直连（自动 bypass 代理）与容器内 `/etc/hosts` 预置；宿主
     `~/.pi/agent/auth.json` 会自动注入容器。密钥仍不落库，groups.yaml 与
     `.local/eval/` 均 gitignored。

约束：全程不得 push、不得改动 `llmanspec/spec/**` 行为合约、不得删除
LLMANSPEC 托管块标记。遇 `init --update` 报错时原样贴出错误并停止。
```
