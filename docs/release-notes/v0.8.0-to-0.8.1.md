```markdown
本项目使用 llman-sdd（spec 驱动开发工作流 CLI）。CLI 已发布 0.8.1，项目 scaffold

   - 运行 `llman-sdd --version`：输出 0.8.1 则跳到第 2 步。

     （propose 阶段未勾 task 走警告，不会卡 strict）。

4. 全量校验
   - 运行 `llman-sdd validate --all --strict`，必须通过；随后按本仓自身门禁惯例跑一遍
     项目质量门禁确认无回归。

说明：本次为 skill 指引修正版，无 breaking、无迁移步骤；`project migrate` 无 0.8.1 条目，
`llman-sdd project migrate` 裸调用可见的已知版本对仍以 0.7.5->0.8.0 为最新。
```
