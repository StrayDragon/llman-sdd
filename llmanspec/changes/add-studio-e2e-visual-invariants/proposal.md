# 建立 Studio 真实浏览器 E2E 视觉不变量与 6 条设计真言自动门禁

## Why

C3 与 C5 的纯函数单测和服务端集成测试能够保证协议、算法与数据状态正确，但无法捕获真实浏览器 CSS 排版后的视觉回归——例如顶栏浮条重叠、抽屉跨屏展开、大卡片文字撑高遮挡邻卡、领域分组框误包非成员节点、或自动连线在真实缩放与字体渲染下穿过无关卡片与叠字。需要将 `studio-web.feature` 中的 **6 条 Studio Web 设计真言** 升级为真实浏览器 DOM/SVG 几何自动断言（L2 门禁），在不拖慢日常秒级 `just qa` 的前提下为 UI 演进提供长期防回归护栏。

## What Changes

- **Playwright 真实浏览器几何断言套件（独立可选门禁 `just qa-studio-e2e`）**：
  - 进程内启动真实 Studio Hub（`startStudioHub({ port: 0, writeHubFile: false })`，零污染用户正在运行的 Hub）（运行时复制本仓全部真实 `llmanspec/specs/` 规格到临时 git 夹具仓，数量动态计数而非写死），驱动无头浏览器执行以下 6 条设计真言的 DOM/SVG 自动断言：
    1. **触点同侧展开**：点击右上角「世界线」按钮后，断言抽屉 `getBoundingClientRect()` 贴靠右侧触发区且与右下角小地图零重叠；
    2. **顶栏浮层单槽互斥**：进入世界线实时对比态/诊断态时，断言顶部中轴同时可见浮条数 `<= 1`（对比条与小贴士绝不重叠）；
    3. **默认连线零穿卡**：遍历主视图与状态机 SVG 边路径，采样点集与所有非端点节点卡片 DOM 包围盒求交，断言穿卡数为 `0`；
    4. **连线与标签互斥 + 手拖生效**：断言所有可见边标签 DOM 矩形两两零重叠，且模拟拖拽连线标签后弧度持久生效；
    5. **领域分组排他隔离**：断言本仓全部真实规格加载后卡片两两零重叠、分组框互不相交且无任何非成员节点落入分组包围盒内；
    6. **产品级视觉与文案洁癖**：扫描渲染后的可见文本，断言不含彩色 Emoji 滥用，且不含「预留 / 占位 / 原型 / `[DEMO-SIM]`」等开发态提示文案。
- **跨工作区状态不丢失端到端回归**：
  - 端到端实测「修改节点/评论/手拖连线弧度 → 立即切换工作区 → 切回原工作区 / 刷新页面」，断言 `flushPendingSaves()` 同步刷盘生效且零数据丢失。
- **生产包零 `[DEMO-SIM]` 门禁**：
  - 断言静态构建产物与真实页面 DOM 中不包含任何原型演示模拟控件，保证所测即上线形态。

## Capabilities

- `studio-web`：将 6 条设计真言与跨工作区持久化契约升级为可重复执行的真实浏览器 E2E 几何验收门禁。

## Impact

- 依赖 `add-studio-web-workbench` 与 `add-studio-forest-tabs` 落地后的完整前端与本地服务。
- 挂接为独立 `just qa-studio-e2e` recipe（及按需 CI job），不阻塞日常秒级 `just qa`。

## Open Questions
