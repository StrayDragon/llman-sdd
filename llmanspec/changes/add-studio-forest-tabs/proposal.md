# 扩展多 Tab 业务森林组合、宏观星图与边界保留下钻

## Why

当项目规模增长到数十个能力与多个业务模块时，人类不仅需要审视单张状态机，还需要把关心的几个业务节点森林自由组合在独立 Tab 里对比交叉逻辑，并能从宏观业务关系一路平滑下钻到微观状态机/流程图，同时不丢失与外部邻居模块的上下文连线。

## What Changes

- **多 Tab 非破坏性视图切片与工作区隔离**：顶部默认仅置顶 1 个 **`📌 全景`** Tab（低认知负担起步），其余自定义 Tab 全部可关闭、支持右键置顶/管理与左上 `‹ / ›` 双向视图历史；点 `+` 进入按当前工作区动态生成的「快速引导页」（动态汇总当前工作区真实规格与 `#tag (count)`，零跨仓串味且含 0 命中空态恢复卡）；视图配置按实例存于本地 `.llman-sdd/studio/views.json`，不改动 `llmanspec/specs/`。
- **宏观业务森林拓扑与领域分组框选**：在宏观全景层使用 `d3-force` 一次性静置排布（严格尊重手拖 `macroPositions`），呈现状态机 / 流程图 / 决策表 / 规则文档 4 类规格节点及自动实线 / 人工虚线，配套 `W3` 孤立规格 Linter 与大图「聚焦邻接」；支持 `Shift+拖框`（或 `V`）批量「打包分组 / 新建 Tab 视图 / 打 Tag」，自定义领域 Tab 支持 `+ 显示外部 1 跳接口` 开关；全景节点与连线同样通过 **`右键 → 留评论`** 或点击未解决 `(N)` 角标接入全站统一就近评论浮窗。
- **单一纯画布 `进入 Tab` 与上下文边界保留（Boundary Portals）**：全景卡片通过显式 **`进入 Tab`** 按钮打开独立完整编辑画布（禁止双击卡片误触展开，不做冗余的只读原地透视或半屏分栏）；进入规格 Tab 后在画布外围渲染自动提取的外部上游约束 / 下游契约门户与跨界虚线，点击门户就近展示 `evidence` 预览卡并提供「新 Tab 打开 / 回到全景」双动作；下钻 2/3 层嵌套子图时无缝衔接盒中盒父层相邻节点投影与贴框面包屑。
- **跨森林交叉桥高亮（Cross-Forest Bridge）**：当自定义组合 Tab 包含 `>= 2` 个领域分组时，提供一键高亮横跨分组的自动契约边并淡化内部非桥接节点，支持右键挂锚定评论汇入统一协商 Prompt 闭环。

## Capabilities

- `studio-web`：扩展多 Tab 组合视角、宏观星图布局切换、边界气泡下钻、路径面包屑与交叉桥高亮行为。

## Impact

- 依赖 `add-studio-web-workbench` 先行夯实单状态机画布与 5 态 UI 交互，再在其上叠装空间导航与多 Tab 容器，避免 MVP 首版过重。

## Open Questions

全部核心决策已收敛并写入同目录 [design.md](./design.md)：

- **宏观星图连线来源**：两层叠加——① **自动实线（0 Token）**：从 `llmanspec/specs/` 扫描跨能力 `@req:rXX` 引用、能力名互引及状态机共享状态/事件生成；② **人工参考虚线（仅存本地 `.llman-sdd/studio/`）**：允许人类在自定义 Tab 里拉辅助关联虚线或视觉分组，以实/虚线明确区分规格事实与个人思考，绝不污染 `llmanspec/specs/`。
- **聚焦核心双向映射，暂不做外部格式导出**：本地仅存紧凑的 `.llman-sdd/studio/views.json`，所有节点句柄直接双向映射回 `llmanspec/specs/` 的真实 `capId` / `@req` / `machineKey`，保持对人类与 Agent 最高效一致的表达；Obsidian `.canvas` / Excalidraw 等外部工具导出明确移出 C5 范围，不在早期分散焦点。
