# 完善 Studio 交互式向导、快捷键体系与画布排版导出体验

## Why

在 MVP 阶段，我们刻意保持顶栏与画布极致克制——将引导收口为固定宽度的静态小贴士条，砍掉了冗余浮窗与外部双向格式导出。当 Studio 进入日常高频使用后，新成员上手与资深用户高效整理复杂大图还需要一组“不打扰默认主画布、按需呼出”的精细打磨能力。

## What Changes

- **「设置 → 交互式引导向导」**：
  - 承接前期定稿的收口规划，在 `画布` 设置面板中提供可随时重播的分步交互向导（高亮指引全景进入 Tab、拖线选建、盒中盒 3 层下钻、右键统一评论浮窗、对比与协商、`保存变更` 护栏），默认不强制弹窗阻断老用户。
- **全局快捷键速查卡（`?`）与键盘流增强**：
  - 按 `?` 弹出按当前视图方言过滤的快捷键速查表（`‹ / ›` 视图历史、`↶ / ↷` 编辑撤重、`Alt+↑` 上层返回、`⌘K` / `⌘F`、`Tab` 速建下游、`Shift+拖框`、`G`/`T` 分组与建 Tab 等），补齐画布焦点节点的键盘微调与无障碍导航。
- **多选排版辅助与只读视觉分享导出**：
  - 针对框选多个节点提供轻量对齐/等距分布与局部重排整理动作（仅更新冷表坐标，不污染语义 Diff）；
  - 提供当前画布高清 **SVG / PNG 只读快照导出**（适配当前亮色皮肤，方便贴入 PR、评审文档或团队沟通），严格不引入 `.canvas`/Excalidraw 等外部双向格式维护负担。

## Capabilities

- `studio-web`：新增按需交互式引导向导、`?` 快捷键速查卡、多选节点对齐整理与只读 SVG/PNG 视觉导出能力。

## Impact

- 依赖 `add-studio-web-workbench` 与 `add-studio-forest-tabs` 的基础画布、设置 SSOT 与多选体系。
- 纯前端体验增强，零后端协议破坏性变更，零 `llmanspec/specs/` 写入风险。

## Open Questions

- 交互式向导是否按用户工作区/浏览器维度记录完成进度，并在首次打开 `--demo` 时提供一键体验入口？
- SVG/PNG 导出是否支持“仅导出当前选中区域 / 导出整张画布 / 带图例与标题栏”三档轻量选项？
